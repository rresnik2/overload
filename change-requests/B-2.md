# B-2: (workout) layout needs ToastProvider + PwaClient (stream E2, no frozen-file change)

B's `ToastProvider` (`@/components/ui/Toast`) and the PWA client (`@/components/shell/PwaClient`) are mounted in `(app)/layout.tsx` via `AppShell`. The `(workout)` layout (stream E2) should mount `ToastProvider` itself (and `PwaClient`, so a waiting service worker is activated once the workout ends) and may reuse the `appleWebApp.startupImage` list from `(app)/layout.tsx`.
